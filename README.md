# Practica de comparacion de fracciones

Mini app web para practicar comparacion de fracciones con un nino.

## Requisitos

- Node.js 18 o superior

## Uso

```bash
npm start
```

Luego abre `http://localhost:3000`.

## Publicarlo gratis en internet

La forma mas simple es usar GitHub Pages.

1. Sube este proyecto a GitHub en la rama `main`.
2. En GitHub entra en `Settings > Pages`.
3. En `Source`, elige `GitHub Actions`.
4. Haz `push` y GitHub lo publicara automaticamente.

La URL final sera algo parecido a:

`https://tu-usuario.github.io/tu-repositorio/`
